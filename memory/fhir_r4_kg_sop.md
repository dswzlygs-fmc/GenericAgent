": "# FHIR R4 → Neo4j 知识图谱构建 SOP\n\n## 目标\n快速将 FHIR R4 JSON 批量导入 Neo4j，形成患者-观察-诊断-用药-手术图谱。\n\n## 前置条件\n1. Python ≥3.8，已装 `fhir.resources==7.0.2` 与 `neo4j` 驱动\n2. Neo4j ≥4.4 运行中，bolt 端口可达\n3. 数据：Synthea/HL7/CMS/MIT-MIMIC 提供的 FHIR R4 Bundle（*.json）\n\n## 坑点速查\n- **保留字冲突**：脚本内变量/类名避免 `class`/`match`/`with`/`where`/`return`/`as`\n- **密码探测**：默认常用密码失败后，脚本自动交互写入 `.neo4j_pwd.txt`，下次直接读取\n- **CSV 中间目录**：`csv_for_neo4j/` 必须复制到 Neo4j 的 `import/` 目录才能 Bulk Load\n- **关系文件**：`rels.csv` 列名含冒号，Neo4j 的 `LOAD CSV` 需用反引号或重命名\n\n## 一键流程\n1. 选数据源 → 运行 `./fhir_dataset_download.sh` 拉取 FHIR Bundle\n2. 生成 CSV：\n   ```bash\n   python skill_fhir_r4_neo4j.py --src ./fhir_bundles/ --out ./csv_for_neo4j/\n   ```\n3. 任选导入：\n   - **直连**：`python skill_fhir_r4_neo4j.py --uri bolt://localhost:7687 --user neo4j --csv ./csv_for_neo4j/`\n   - **Bulk**：复制 `csv_for_neo4j/` → Neo4j `import/`，浏览器执行 `bulk_load_neo4j.cypher`\n\n## 验证\n```cypher\nMATCH (n) RETURN labels(n)[0] AS label, count(*) AS count;\n```\n\n## 扩展\n- 新增资源：在脚本 `NODE_TYPES`/`REL_MAP` 追加映射即可\n- 大数据：使用 `neo4j-admin import` 离线模式，先关库后导入\n
